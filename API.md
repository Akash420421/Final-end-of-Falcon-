# API & Data Access Layer Specification (API.md)
## Project: Falcon Electricals – B2B Switch Showcase & CMS Platform
**Document Version:** 2.0.0  
**Integration Type:** Real-Time Cloud Firestore SDK + Client-Side REST-Like Mutations + External B2B Messaging APIs

## 1. Architectural Overview

Falcon Electricals leverages Google Cloud Firestore SDK v10+ with real-time reactive snapshot listeners (`onSnapshot`) for lightning-fast reads, paired with structured asynchronous mutation methods in `StoreContext.tsx`. External B2B lead dispatch is handled via standardized WhatsApp Web/Mobile Click-to-Chat URI protocols and tel/mailto schemas.

```
+-----------------------------------------------------------------------------------+
|                                 CLIENT APPLICATION                                |
|  +-----------------------------------------------------------------------------+  |
|  |             StoreContext Data Access Layer (`useFalconStore`)               |  |
|  |  ├── fetchProducts()          ├── addProduct()                              |  |
|  |  ├── fetchCategories()        ├── updateProduct()                           |  |
|  |  ├── fetchCompanyBranding()   ├── deleteProduct()                           |  |
|  |  └── uploadOrCompressImage()  ├── updateCompanyBranding()                   |  |
|  +-----------------------------------------------------------------------------+  |
+--------------------------|---------------------------------|----------------------+

                           ▼                                 ▼
+------------------------------------------+  +-------------------------------------+
|        Google Cloud Firestore DB         |  |      External Service APIs          |

```

## 2. Firestore Data Access Layer (Methods & Signatures)

All database operations are encapsulated in `src/context/StoreContext.tsx`.

---

### 2.1 Store Branding API

#### Method: `updateCompanyBranding(data: Partial<CompanyDetails>): Promise<void>`
* **Description:** Persists updated company name, tagline, phones, WhatsApp, address, GSTIN, and working hours to `store_settings/company_branding`.
* **Path:** `store_settings/company_branding`
* **Input Payload:**
```typescript
interface UpdateBrandingPayload {
  companyName?: string;
  brandName?: string;
  tagline?: string;
  phone?: string;
  secondaryPhone?: string;
  whatsapp?: string;
  email?: string;
  address?: string;
  gstin?: string;
  workingHours?: string;
  logoUrl?: string;          // Auto-compressed Base64
  switchImageUrl?: string;   // Auto-compressed Base64
  heroBadge?: string;
}
```
* **Success Response:** `void` (Triggers optimistic local state update + success toast).
* **Error Handling:** Catches Firestore errors, reverts state, and displays human-readable error notification.

---

### 2.2 Products Management API

#### Method: `addProduct(product: Omit<Product, 'id'>): Promise<string>`
* **Description:** Creates a new SKU document in the `products` collection with automatic client-side image compression.
* **Path:** `products/{autoGeneratedId}`
* **Input Payload:**
```typescript
interface NewProductPayload {
  name: string;              // "Falcon 10A 1-Way Switch"
  category: string;          // "modular-switches"
  categoryName: string;      // "Modular Switches"
  code: string;              // "FAL-MOD-101"
  description: string;       // "Flame retardant 1-module switch"
  amps?: string;             // "10A 240V~"
  price: number;             // 68.00
  moq?: string;              // "100 Pcs"
  image: string;             // Base64 or preset key
  images?: string[];         // Array of Base64 photos (Max 6)
  specs: Record<string, string>;
  isNew?: boolean;
  isPopular?: boolean;
}
```
* **Response:** Returns `productId: string` (e.g., `"prod_1723829102931"`).

---

#### Method: `updateProduct(id: string, payload: Partial<Product>): Promise<void>`
* **Description:** Updates existing SKU fields, technical specifications, pricing, or product images.
* **Path:** `products/{id}`
* **Input Payload:**
```typescript
{
  name?: string;
  price?: number;
  specs?: Record<string, string>;
  images?: string[];
  isPopular?: boolean;
  isNew?: boolean;
}
```
* **Response:** `void`.

---

#### Method: `deleteProduct(id: string): Promise<void>`
* **Description:** Deletes a product document from Firestore.
* **Path:** `products/{id}`
* **Response:** `void`.

---

### 2.3 Category Management API

#### Method: `addCategory(category: Omit<Category, 'id'>): Promise<string>`
* **Path:** `categories/{categoryId}`
* **Input Payload:**
```typescript
{
  title: string;             // "Modular Switches"
  subtitle?: string;         // "10A & 20A FR Grade"
  iconName: string;          // "ToggleLeft"
  image?: string;
  displayOrder?: number;
}
```

---

#### Method: `deleteCategory(id: string): Promise<void>`
* **Path:** `categories/{id}`
* **Behavior:** Deletes category document. Optionally handles product re-assignment.

---

### 2.4 Database Utility & Recovery API

#### Method: `resetToDefaultCatalog(): Promise<void>`
* **Description:** Re-seeds default factory catalog (`src/data/initialData.ts`) into Firestore collections (`products`, `categories`, `store_settings`).
* **Use Case:** Emergency restoration / initial deployment bootstrap.

## 3. External Messaging & Communication APIs

### 3.1 WhatsApp B2B Click-to-Chat API

#### Schema: `https://wa.me/{cleanPhoneNumber}?text={encodedMessage}`

* **Endpoint:** `https://wa.me/`
* **Method:** `GET` (Client-side URL Redirection / New Tab)
* **Parameters:**
  - `cleanPhoneNumber`: 10 to 12 digit international format without symbols (e.g. `919717549515`).
  - `text`: URL-encoded query message.

#### Message Payload Templates:

1. **General Catalog Inquiry:**
```
Hello Verma Enterprises (Falcon Electrics), I am looking for catalog & bulk pricing details.
```

2. **Specific SKU Inquiry:**
```
Hello Verma Enterprises (Falcon Electrics), I am interested in ordering: Falcon 10A 1-Way Modular Switch (Code: FAL-MOD-101). Please share dealer quote.
```

3. **Structured Quotation Form Submission:**
```
Hello Falcon Electricals,
*New Wholesale Quotation Request:*
- *Dealer Name:* Rajesh Electricals
- *City/State:* Jaipur, Rajasthan
- *Phone:* +91 98290 12345
- *Product:* Falcon 16A Power Socket (FAL-SOC-201)
- *Required Qty:* 500 pcs (5 Master Boxes)
- *Notes:* Urgent dispatch required.
```

## 4. Request & Response Rules & Error Handling

### 4.1 Strict Payload Size Rule (Firestore 1MB Safeguard)
* All binary images uploaded via Admin CMS are **intercepted by `compressImageFile`** before sending to Firestore.
* Maximum payload per image: $\le 320\text{ KB}$ Base64 string.
* Rejection limit: File uploads $\ge 20\text{ MB}$ raw size are rejected with validation alert before canvas processing.

### 4.2 Network Resiliency & Error Status Codes
* **Offline / Slow Connection:** When Firestore is offline, `StoreContext` serves cached in-memory state and shows a non-intrusive banner (`Firebase Connection Notice`) with a **"Retry Connection"** action button.
* **Validation Error (Client):** Input fields highlight in red (`ring-2 ring-red-500`) with shake animations.
* **Success Feedback:** All write operations trigger a standard 3000ms toast notification (`✅ Saved to Cloud`).
